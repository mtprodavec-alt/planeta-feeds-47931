# Planeta → PriceCreator, магазин «Червоний жук» (47931)

Щоночі о 03:00 за Києвом GitHub Actions:
1. скачує 7 фідів «Планети» (токен у секреті `PLANETA_FEED_TOKEN`);
2. перевіряє їх: якщо фід не скачався або впав більш ніж на 20 %, запуск зупиняється, і вчорашні файли лишаються;
3. об'єднує фіди й зіставляє з магазином за `config/store.csv` (артикул = vendorCode Планети → OFFERID магазину);
4. рахує ціну і публікує на GitHub Pages **один фід** `feed.xml`:
   - наявні товари — з OFFERID магазину, новою ціною й залишком (короткий опис, бо PriceCreator бере опис лише при першому імпорті);
   - нові товари — з повним змістом, offer id `JUK` + 10 символів хешу, артикул `JUK-<vendorCode>`;
   - `report.json` — підсумок запуску. Якщо фід перевищить 95 МБ, запуск зупиниться, а вчорашній фід лишиться.

## Ціна
`(опт × k + 30 + Smart) / (0,75 − комісія)`, округлення вгору, не нижче чинної ціни з `store.csv`.
k = 1,25 і Smart 12 / 18 / 30 грн до 400 / 700 / 3000 грн; від 3000 грн k = 1,15, Smart 30 грн.
Комісія = відсоток із довідника × 1,08 (так рахує Rozetka, звірено з `commission_sum`). Звідки береться відсоток:
1. категорія є в `config/tariff.xlsx` → тариф за категорією, брендом і ціновим діапазоном;
2. інакше → комісія товару з вивантаження комісій Rozetka;
3. інакше → максимальна комісія в цій категорії Rozetka, далі максимальна по магазину;
4. для новинок → максимальна комісія серед уже зіставлених товарів тієї ж категорії Планети.

## Налаштування (один раз)
1. Створити **публічний** репозиторій (безкоштовні Pages працюють лише з публічними) і завантажити туди цю папку разом із `.github`.
2. Settings → Secrets and variables → Actions → New secret `PLANETA_FEED_TOKEN` = токен Планети.
3. Settings → Pages → Source: **GitHub Actions**.
4. Actions → «Planeta -> PriceCreator nightly sync» → Run workflow. Файли з'являться за адресою `https://<логін>.github.io/<репозиторій>/stock.xml`.
5. PriceCreator → Імпорт товарів → XML → Імпорт: посилання на `feed.xml`, «Вимкнути відсутні» вимкнено → Старт імпорту. Далі Автооновлення: увімкнути це джерело (ціни й залишки щогодини).
6. Автооновлення нових товарів не додає: щоб підтягнути новинки, яких додала Планета, повторно натискайте «Старт імпорту» з тим самим посиланням.

У репозиторії немає оптових цін і токена. Публічні в ньому лише роздрібні ціни, OFFERID і категорії Rozetka.

## Розпродаж Планети
Щоночі `tools/parse_sale.py` збирає https://planeta-shop.com.ua/rasprodazha (стара й акційна ціна кожної картки).
Картка зіставляється з офферами фіду за кодом моделі (частина vendorCode до першого `_`): з варіантів картки або з назви.
Береться лише оффер, у якого роздрібна ціна у фіді дорівнює старій ціні на сайті.
Для такого товару закупівля = акційний опт = опт із фіду × (акційна / стара) (наприклад 880 × 660/1320 = 440), ціна рахується за формулою без правила «не нижче чинної»,
а стара ціна = звичайна ціна товару (за якою він продавався до розпродажу). Коли товар зникає з розпродажу, повертається звичайна ціна.
Якщо сторінка розпродажу не відкрилась, береться список попереднього запуску (`sale.json` на сайті фіду).

## Нові товари
Workflow порівнює список нових offer id (`new_ids.txt`) з попереднім запуском і, якщо з'явились нові товари,
запускає в PriceCreator імпорт джерела 34503 (секрет `PRICECREATOR_UUID`). Наявні картки при цьому лише оновлюються.
